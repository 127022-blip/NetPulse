NetPulse 2.0.55 使用说明

一、安装与启动
1. 打开本文件夹中的 NetPulse-2.0.55.app
2. 若 macOS 提示无法验证开发者：系统设置 → 隐私与安全性 → 仍要打开
3. 启动后在菜单栏显示网速 / CPU / 内存 / 磁盘 / CPU 温度（依设置模式；「仅图标」只显示图标）

二、常用操作
- 左键点击菜单栏图标：打开下拉面板（紧贴该状态栏项正下方，顶部固定）
- 右键：打开面板 / 设置… / 关于 / 退出
- 面板内可查看网络状态、系统状态（CPU / MEM / SSD / TEMP）、实时速度与波形、今日与近 5 日流量
- 「设置」可改刷新间隔、菜单栏显示模式、告警与登录项
- 标题栏与设置页的主题选择已同步：在任一处改为浅色 / 深色 / 跟随系统，另一处立刻更新，实际外观一致
- 「退出」会先弹出轻确认，避免误关
- 「关于」窗口隐藏标题栏文字，以图标与英文名称「NetPulse」为主视觉，无中文程序说明行、无中间描边卡片、无底部分割线，背景为系统窗口色；高度已收紧，图标更靠近顶部；名称、版本与版权均为中性色（无彩色字），版本写成「版本 2.0.55（255）」；「完成」为克制的普通按钮，也可按 Return / Esc 或左上角关闭

三、菜单栏显示模式
- 仅图标：显示彩色程序应用图标（不是白色模板、不是心跳图标）
- 图标 + 下载速度 / 图标 + 上下速度 / 图标 + CPU：同时显示程序图标与对应文字，CPU 温度在最末尾（如「42°」）
- 网速 + 系统（推荐）：显示上下网速与 CPU / 内存 / 磁盘，CPU 温度在最右侧；第二行标签为 CPU、MEM、SSD、TEMP。四列按 TEMP 的宽度统一排列并对齐，CPU / MEM / SSD 三个字母在与 TEMP 同宽的槽位内水平居中；上行数值与对应标签列对齐并居中。不附带左侧图标
- 温度读不到时显示「--°」，不会显示 0°
- 设置页「网速 + 系统」预览同样为双行，四列同宽，温度列下为 TEMP 标签，三字母居中；带温度数字的模式预览按与状态栏相同的规则示意变色

四、设置窗口（沿用 2.0.41，确认框改为设置窗 Sheet）
- 卡片样式与主弹窗一致（浅描边，无大阴影）；窗口可上下缩放，宽度固定
- 「刷新」与「通知与告警」分卡；告警选项默认折叠
- 可查看通知权限并请求授权 / 打开系统设置
- 菜单栏显示模式带效果预览与「推荐」标注
- 数据管理支持重置今日流量与恢复默认设置；取消为默认按钮，破坏性操作需再次确认
- 「恢复默认设置」会将主题一并恢复为跟随系统，设置页与主弹窗同时生效
- 状态栏 CPU 温度默认常显，设置窗不另增加关

五、弹窗锚定说明（沿用 2.0.40）
- 弹窗顶部固定在状态栏项下沿正下方；内容变高/变矮时顶部位置不变
- 弹窗水平中心与所点击的状态栏项对齐
- 「系统状态」卡在 CPU / MEM / SSD 下方显示 TEMP 行，与上三行完全同一套样式（标签、行高、间距、右侧数值、中间横向进度条）。温度按 100°C 上限换算条长，超过则条满；颜色沿用占用阈值。约 1.5 秒随已有读温快照刷新；读不到显示空条与「--°」

六、颜色说明（弹窗与状态栏共用）
- ↓ 下载：青色 #00C7BE
- ↑ 上传：蓝色 #007AFF
- 已连接：绿色 #34C759；已断开：红色 #FF3B30
- CPU / MEM / SSD 占用：≤50 默认色；>50 黄；>80 橙；>90 红
- 弹窗 TEMP 进度条、弹窗 TEMP 数字、状态栏温度数字：先把摄氏度按上限 100°C 换成 0–100 比例（min(max(celsius, 0) / 100, 1) × 100），再套用同一套占用阈值变色。读不到时状态栏与弹窗均显示「--°」，为次要灰色，不把缺失当作 0 变色
- 状态栏「网速 + 系统」第二行 TEMP 标签保持次要色，只变上行温度数字的颜色
- 磁盘读失败且无历史成功值时显示「磁盘：--」

七、权限
- 显示 Wi-Fi 名称（SSID）需要「位置」权限；拒绝时标题显示接口名，并提示「要显示网络名称，请允许位置权限」，不影响网速统计
- 告警通知需要系统「通知」权限；可在设置页请求或前往系统设置开启
- 读取 CPU 温度使用 AppleSMC / IOKit，无需额外权限，也不使用 sudo powermetrics
